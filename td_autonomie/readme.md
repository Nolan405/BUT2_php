# Quiz App - PHP Orienté Objet & PDO

Bienvenue sur notre application de Quiz. Identifiez-vous pour accéder au questionnaire, testez vos connaissances et comparez votre score avec celui des autres joueurs dans le classement général.

## Installation et Lancement

Pour lancer le projet, assurez-vous d'être à la racine du dossier `td_autonomie` dans votre terminal, puis exécutez la commande suivante :

```bash
php -S localhost:8000 -t _incr _incr/router.php
